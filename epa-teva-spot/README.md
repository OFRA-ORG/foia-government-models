# EPA — TEVA-SPOT / Water Security Toolkit

**Agency:** U.S. Environmental Protection Agency (Office of Research and Development / CESER)

**FOIA:** PPT to EPA; final responses 2026-EPA-03247 and 2026-EPA-03258 (full grant, publicly available)

## Description

The Threat Ensemble Vulnerability Assessment - Sensor Placement Optimization Tool (TEVA-SPOT), superseded by and folded into the Water Security Toolkit (WST): water-distribution contamination-warning-system design, impact assessment, and sensor placement optimization.
