# BOEM — Well Economic Boundary Model (WEB3)

**Agency:** U.S. Department of the Interior, Bureau of Ocean Energy Management (BOEM)
**FOIA Request Number:** DOI-2026-004970
**Date of Final Response:** April 2026

## Description

Source code for BOEM's Well Economic Boundary (WEB3) model, used to evaluate the economic viability of offshore oil and gas wells and determine production thresholds for lease compliance. The model is implemented as a C# Windows Forms application.

## Contents

- `ConsoleApplication1/` — Full Visual Studio C# project source code
  - `Program.cs` — Application entry point
  - `Input.cs` — Input handling
  - `ContainsCosts.cs`, `CustomCosts.cs` — Cost modeling logic
  - `ResultsViewer.cs` — Results display
  - `SaveXML.cs` — XML output
  - `Web30Form.cs` — Main application form
  - `WEB30.csproj`, `WEB30.sln` — Visual Studio project and solution files
  - `Properties/AssemblyInfo.cs` — Assembly metadata
- `DOI-2026-004970_Part II - User Manual for WEB 2.PDF` — Official user manual
- `2026_0428_DOI-20226-004970_Release 1_Letter.pdf` — Agency FOIA response letter
