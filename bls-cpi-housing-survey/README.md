# BLS — CPI Housing Survey Collection Instruments

**Agency:** U.S. Department of Labor, Bureau of Labor Statistics (BLS)
**FOIA Request Number:** 2026-F-06065
**Date of Final Response:** 2026

## Description

Survey collection instruments, methodology documentation, and supporting materials for the Consumer Price Index (CPI) Housing Survey, which underpins the shelter component of the CPI.
