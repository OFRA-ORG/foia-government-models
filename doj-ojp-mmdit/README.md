**Date of Final Response:** July 10, 2026

> **Note:** This directory links to the tool rather than mirroring it. In response to the request for source code and model artifacts, OJP produced no records of its own and instead listed links to NIJ publications and the grantee's public repositories. The code is authored by third-party NIJ grantees. The linked repositories are actively maintained and change over time; the pinned commits under **Source** identify the exact state reviewed on 2026-08-10.

## Description

MMDIT (Mitochondrial Mixture Database and Interpretation Tool) is a forensic tool for the deconvolution and interpretation of mitochondrial DNA (mtDNA) mixtures, developed under NIJ award 2017-DN-BX-0134. It comprises a core library and an R Shiny user interface, with a companion hosted web application.
