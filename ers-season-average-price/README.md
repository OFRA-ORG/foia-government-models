**Date of Final Response:** June 17, 2026
**Version:** June 2026 (data current as of June 4, 2026)

> **Note:** This repository contains a snapshot of the model and data as of June 2026. The most current version — including the latest weekly forecast data and any updated model parameters — is maintained by ERS at:
> https://www.ers.usda.gov/data-products/season-average-price-forecasts

## Description

The Season-Average Price / Market Year Average (MYA) Price Forecast model produces national average price forecasts for the prices farmers receive for four major commodities — corn, soybeans, wheat, and upland cotton — over their respective 12-month marketing years. Forecasts are generated by combining USDA NASS price-received data with nearby futures settlement prices, adjusted for historical basis and weighted by historical marketing percentages.

The model outputs directly inform two farm bill commodity support programs:

- **Price Loss Coverage (PLC):** using the model's MYA forecast to estimate whether an effective price will fall below the statutory effective reference price, and by how much
- **Agricultural Risk Coverage (ARC):** using a 5-year Olympic average of historical MYA prices to set ARC-CO and ARC-IC revenue benchmarks

ERS notes that these are not official USDA forecasts; official projections are published separately in USDA's WASDE reports. The model runs in parallel with WASDE and both are presented side by side in the outputs.

## Forecasting Methodology

For each marketing month, the model:

1. Uses the actual NASS price received when available
2. Otherwise forecasts the month's price as: nearby futures price + historical basis average
3. Where neither is available, interpolates using the average of adjacent months
4. Weights each month's composite price by a historical marketing percentage
5. Sums the weighted prices across all marketing months to produce the MYA forecast

Historical basis and marketing percentages are 5-year averages for corn, soybeans, and wheat, and 7-year Olympic averages for cotton. These parameters are hardcoded in the spreadsheet and updated annually.

**Wheat uses a three-contract aggregate** for marketing years 2021/22 and beyond: a production-weighted average of nearby CBOT (soft red winter), KCBT (hard red winter), and MGE (spring wheat) contracts. The production weights update annually based on USDA wheat production by class data. For 2025/26 the weights are approximately 29% Chicago / 41% Kansas City / 29% Minneapolis; for 2026/27 they are approximately 34% / 33% / 33%.

**Cotton** does not include PLC or ARC payment calculations; only MYA price forecasts are produced. This reflects cotton's separate farm bill support structure.

## What Updates and When

| Component | Update frequency |
|---|---|
| Futures prices (column D in Excel) | Weekly — user-entered from exchange |
| Actual NASS prices received (column B) | Monthly as NASS releases data |
| WASDE official projection | Monthly following WASDE release |
| Basis averages, marketing percentages | Annually |
| Historical MYA prices (for ARC/PLC calculations) | Annually |
| Wheat production weights | Annually |
| Farm bill parameters (reference prices, loan rates) | Farm bill cycle |

## Contents

### `futmodel-calculator.xlsx`

The complete forecast model implemented as Excel formulas. Contains 8 sheets — one for the current marketing year and one for the next marketing year for each commodity:

| Sheet | Commodity | Marketing year |
|---|---|---|
| Corn25 | Corn | 2025/26 |
| Corn26 | Corn | 2026/27 |
| Wheat25 | Wheat | 2025/26 |
| Wheat26 | Wheat | 2026/27 |
| Soy25 | Soybeans | 2025/26 |
| Soy26 | Soybeans | 2026/27 |
| Cotton25 | Upland Cotton | 2025/26 |
| Cotton26 | Upland Cotton | 2026/27 |

Each sheet is self-contained. All basis values, marketing percentages, historical MYA prices, and farm bill parameters are hardcoded. To generate a forecast, a user need only enter current weekly futures settlement prices in the designated column. Formulas are visible via `Ctrl+~`. Data sources: LSEG Data & Analytics (formerly Refinitiv) for futures prices; USDA NASS for prices received and marketing data.

### `inputdata.csv`

Archival dataset of historical model inputs covering marketing years 1994 through the present (129,378 records). This file is a standalone reference record — it is **not** directly fed into the Excel calculator, which uses its own hardcoded parameter values derived from the same underlying sources. Fields:

| Field | Description |
|---|---|
| `commodity` | Corn, Soybeans, Wheat, or Cotton |
| `item` | Data series (futures prices, basis, marketing percentages, WASDE forecasts, prices received, farm bill parameters, wheat contract weights, wheat production by class) |
| `futures_exchange` | CBOT, KCBT, MGE, ICE, or weighted aggregates |
| `commodity_class` | Wheat class subdivision where applicable |
| `data_period` | Monthly or Yearly |
| `marketing_year` | Crop marketing year |
| `calendar_year_month` | Calendar month of observation |
| `futures_contract` | Contract month used |
| `data_source_date` | Date the value was sourced |
| `value` | Numeric value |
| `unit` | Unit of measurement |

### `outputfc.csv`

Archived weekly forecast outputs from May 2003 through June 2026, covering marketing years 2002–2027 (11,427 records). Two model types are present: `Single contract` (corn, soybeans, cotton, and wheat prior to 2021/22) and `Three contract aggregate` (wheat 2021/22 onward). Fields include model-based and WASDE-based MYA price forecasts, PLC effective prices and payment rate forecasts, ARC-CO and ARC-IC benchmark and effective prices, 5-year Olympic average inputs, and actual realized MYA prices where available.
