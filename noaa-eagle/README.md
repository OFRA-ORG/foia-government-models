## Description

Project EAGLE ("Experimental AI Global and Limited-area Ensemble forecast system") is a joint NOAA / National Weather Service effort that provides the ability to rapidly test, develop, and demonstrate near-real-time artificial-intelligence (AI) models for global and limited-area ensemble weather forecasting, and to evaluate AI model performance against the metrics used for traditional NOAA prediction systems such as the Global Forecast System (GFS) and Global Ensemble Forecast System (GEFS).
